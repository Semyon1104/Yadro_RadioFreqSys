## Примеры использования "static"
### Статические переменные внутри функции
Статические переменные при использовании внутри функции инициализируются только один раз, а затем они сохраняют свое значение. Эти статические переменные хранятся в статической области памяти (.data или .bss), а не в стеке
Пример:
```c++
void counter() {
    static int count = 0; // Инициализируется один раз
    count++;
    std::cout << "Count: " << count << std::endl;
}

int main() {
    counter(); // Count: 1
    counter(); // Count: 2
    counter(); // Count: 3
    return 0;
}
```

### Статические объекты класса
При использовании ключевого слова **static** разрушение объекта созданного в локальной области видимости произойдет только по завершении работы программы, а не при выходе из блока программы, в которой он был создан.

### Статические члены класса
#### Поле
Статические члены класса принадлежат самому классу, а не его экземплярам.
Пример статического поля:
```c++
class MyClass {
public:
    static int sharedValue; // Общая для всех объектов
};

// Обязательно проинициализировать
int MyClass::sharedValue = 0;

int main() {
    MyClass obj1, obj2;
    obj1.sharedValue = 5;
    std::cout << obj2.sharedValue << std::endl; // 5
    return 0;
}
```
#### Метод
Статический метод можно вызывать без создания объекта.
* Внутри функции обращаться можно только к статическим членам данных, другим статическим функциям-членам и любым другим функциям извне класса.
* Статические функции-члены имеют область видимости класса, в котором они находятся.
* Вы не имеете доступа к указателю this класса, потому что мы не создаем никакого объекта для вызова этой функции.
Пример статического метода:
```c++
class MathUtils {
public:
    static int square(int x) {
        return x * x;
    }
};

// Доступ к статическим функциям осуществляется с использованием имени класса и оператора разрешения области видимости (::)
int main() {
    std::cout << MathUtils::square(5) << std::endl; // 25
    return 0;
}
```

### Статические функции

Используя static для функции, мы можем ограничить область видимости этой функции, и данная функция не будет видна в других файлах одного проекта, если это не заголовочный файл. То есть не возникнет ошибки, если функции названы одинаково.

## Примеры использования "using"

**Using** используется для введения имен из пространства имен или определения псевдонимов для типов данных. Это позволяет значительно сократить объем кода и сделать его более понятным. Основные виды using-стейтментов включают:

* **using-директива** для пространств имен
```c++
using namespace std;
  
  int main() {
      cout << "Hello, world!" << endl; //std::cout и std::endl
      return 0;
  }
```
* **using-объявление** для имен - если вам нужно использовать только отдельные имена из пространства имен, вы можете воспользоваться using-объявлением:
```c++
  using std::cout;
  using std::endl;
  
  int main() {
      cout << "Hello, world!" << endl;
      return 0;
  }
  ```
* **using-псевдонимы** для типов
```c++
using StrMap = std::map; //создаем псевдоним, а не новый тип
  
  int main() {
      StrMap myMap;
      myMap["key"] = "value";
      return 0;
  }
```

## Примеры использования "static"
Слово **inline** используется для предложения компилятору вставить код функции непосредственно в точку вызова функции, вместо фактического вызова функции.

**Inline** можно использовать если мы вызываем небольшую функцию многократно, а также в заголовочных файлах, чтобы избежать проблем с множественным определением при включении в несколько файлов.

Пример с заголовочным файлом:
```c++
// constants.h
#ifndef CONSTANTS_H
#define CONSTANTS_H
 
namespace constants
{
    inline constexpr double pi { 3.14159 };
    inline constexpr double avogadro { 6.0221413e23 };
    inline constexpr double my_gravity { 9.2 };
}
#endif
```
```c++
// main.cpp
#include "constants.h"
 
#include <iostream>
 
int main()
{
    std::cout << "Enter a radius: ";
    int radius{};
    std::cin >> radius;
 
    std::cout << "The circumference is: " << 2.0 * radius * constants::pi << '\n';
 
    return 0;
}
```
Мы можем включать constants.h в любое количество cpp-файлов, но эти переменные будут созданы только один раз и совместно использоваться во всех файлах с кодом.
